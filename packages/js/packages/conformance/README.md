# @ckvf/conformance

Runs CKVF test vectors against `@ckvf/node` and emits machine-readable profile results:

- CKVF Core compliant
- CKVF OpenPGP Profile compliant
- CKVF S/MIME Profile compliant
- CKVF Email Identity Proof compliant
- CKVF DNS Identity Proof compliant

Pin a test-vector **VERSION** (currently `0.1.0`). Do not float on `main`.
