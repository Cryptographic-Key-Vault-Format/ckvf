# Support

CKVF is the SComm.AI-maintained portable vault format, published at [scomm-public/ckvf](https://github.com/scomm-public/ckvf).

## How to get help

| Question | Where |
| --- | --- |
| How does the format work? | [specification/SPEC.md](specification/SPEC.md) |
| Schema or field names | [schemas/](schemas/) |
| Algorithm / family / encoding identifiers | [registries/](registries/) |
| Interoperability fixtures | [test-vectors/](test-vectors/) (pin `VERSION`) |
| JavaScript/TypeScript usage | [packages/js](packages/js) |
| Dart usage | [packages/dart](packages/dart) |
| Ambiguity that could split implementations | Open a GitHub issue on this repository |
| Vulnerability | [SECURITY.md](SECURITY.md) — do not file a public issue |
| Conduct | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Implementations SHOULD use the pinned test vectors and conformance profiles.

Questions about hosted Discovery / `pubkey.scomm.ai` belong with that service unless they are CKVF container defects.
